# sentiment-analysis
# 😊 Sentiment Analysis Web App
A simple 🤖 Machine Learning based web application that analyzes a user's text/review and predicts whether the sentiment is **Positive 😊** or **Negative 😞**.
---

## 📌 Project Overview
This project uses **Machine Learning + Flask** to build a web-based Sentiment Analysis application.
The user enters a review in the web interface, and the trained Machine Learning model analyzes the text and provides:

- 😊 Positive or Negative sentiment
- 📊 Prediction confidence
- 🌐 Simple web interface

## 🧠 Machine Learning

This project uses **Natural Language Processing (NLP)** techniques for sentiment classification.

### 🔢 TF-IDF Vectorizer

TF-IDF converts text data into numerical features so that the Machine Learning model can process the review.

### 🤖 Multinomial Naive Bayes

Multinomial Naive Bayes is used as the Machine Learning classification algorithm.

The model is trained using positive 😊 and negative 😞 review examples.
